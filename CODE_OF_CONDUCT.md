# Code of Conduct

## Our standard

Be direct, technically honest, and respectful. Critique ideas and evidence rather than people.

Unacceptable behavior includes harassment, discrimination, publishing private information, and knowingly submitting malicious or misleading automation.

## Scope

This standard applies to repository discussions, issues, pull requests, reviews, and other project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers through a contact method listed on the repository profile. Maintainers may edit or remove contributions and may restrict participation when necessary.

## Attribution

This short policy is informed by common open-source community standards, including the Contributor Covenant, but is intentionally minimal for a small template project.
