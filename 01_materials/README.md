# Materials

> Store original evidence here. Treat every file in this directory as read-only.

Recommended subdirectories:

```text
01_materials/
├── attachments/
├── papers/
├── transcripts/
└── web/
```

Rules:

- Preserve original filenames when they carry provenance.
- Do not rewrite PDFs, transcripts, or screenshots to match the knowledge-card style.
- Put derived conclusions in `10_domains/`, not in the source file.
- Keep private or confidential evidence out of public repositories.
- Redact personal identifiers before publishing screenshots.

The change scanner ignores this directory.
